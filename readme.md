# Shop Checker Bot

Моніторинг каталогу монет НБУ через Playwright зі сповіщеннями в Telegram.
Порівнює товари з фіксованим знімком `products.json` за ID, назвою та URL.
Ціна й наявність поки не відстежуються. Знімок автоматично не змінюється.

## Налаштування та запуск

Потрібні Node.js 24+ і pnpm 11.24.0. TypeScript запускається без збірки.

```sh
pnpm install
pnpm exec playwright install chromium
```

Створіть `.env` за прикладом `.env.example`:

```env
BOT_TOKEN=your_bot_token
CHAT_ID=your_chat_id
```

Спочатку відкрийте свого бота в Telegram і натисніть Start.
Команди запуску завантажують `.env`; цей файл виключено з Git.
Базовий список `products.json` має бути в корені проєкту.

```sh
pnpm start       # запуск моніторингу
pnpm dev         # перезапуск після змін коду
pnpm typecheck   # перевірка типів
```

## Як працює

- `main.ts` запускає один видимий браузер і послідовно виконує перевірки.
- Кожна перевірка відкриває нову сторінку, чекає до 5 секунд на перше
  посилання товару та ще 1 секунду перед читанням списку. Ця затримка
  не гарантує завантаження всіх динамічних елементів.
- Після перевірки програма надсилає повідомлення, чекає заданий інтервал,
  закриває сторінку й починає наступну перевірку.
- Без змін повідомлення містить перші 30 символів назви кожного товару.
- За наявності змін — списки доданих, змінених і відсутніх товарів
  із повними назвами, ID та URL.
- Повідомлення довші за 4 000 символів обрізаються з позначкою `[Message truncated]`.
- Без змін повідомлення надсилається під час першої успішної перевірки без змін,
  а далі — не частіше ніж раз на 3 години. Час зберігається в пам’яті;
  після перезапуску перше повідомлення без змін надсилається знову.
- За наявності відмінностей від фіксованого знімка повідомлення надсилається
  після кожної перевірки, без очікування цього інтервалу.

Налаштування в `src/variables.ts`:

| Константа | Поточне значення |
| --- | --- |
| `CHECK_INTERVAL_MS` | 20 секунд після завершення перевірки |
| `PRODUCT_LOAD_DELAY_MS` | 1 секунда перед читанням товарів |
| `PRODUCT_WAIT_TIMEOUT_MS` | 5 секунд очікування першого посилання |
| `TELEGRAM_MAX_MESSAGE_LENGTH` | 4 000 символів разом із позначкою обрізання |
| `NO_CHANGE_MESSAGE_INTERVAL_MS` | 3 години між повідомленнями без змін |

Зупинка: Ctrl+C. Комп’ютер має бути увімкнений, не спати й мати інтернет.
Наразі помилка перевірки або Telegram (зокрема HTTP 403) завершує
моніторинг і закриває браузер. Автоматичного повтору після помилки немає.
