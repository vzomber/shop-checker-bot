# Shop Checker Bot

Проєкт для моніторингу каталогу монет НБУ та сповіщень у Telegram.
Наразі проєкт відкриває каталог у Chromium через Playwright; моніторинг і Telegram ще не реалізовані.

## Запуск

Потрібен Node.js 24 або новіший і pnpm 11.24.0. Перед першим запуском виконайте `pnpm install`.
Node.js запускає TypeScript напряму, без окремої збірки та перевірки типів.

Перед першим запуском встановіть браузер:

```sh
pnpm exec playwright install chromium
```

```sh
pnpm start
```

Автоматичний перезапуск після змін:

```sh
pnpm dev
```

Перевірка типів (TypeScript і `@types/node` використовуються лише для розробки):

```sh
pnpm typecheck
```

Точка входу — `run.ts`, головна функція — `main()`.
Вона викликає `openCatalog()`, що відкриває каталог у видимому вікні браузера.
Щоб завершити роботу, закрийте вікно браузера.

`products.json` — фіксований знімок каталогу. Кожен запуск порівнює сайт
із цим файлом за ID та показує додані, відсутні товари й зміни назви або URL.
Програма лише читає цей файл і ніколи не оновлює його автоматично.
Ціна та наявність поки не порівнюються.
